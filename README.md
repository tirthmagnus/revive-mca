# Revive MCA

Custom mobile-first Next.js lead-generation and digital-identity site for revivemca.com.

## Included
- Distinct custom visual identity for this domain
- Mobile-first responsive UI
- Name + phone as the only required lead contact fields
- Rule-based chatbot, no AI API
- Multi-step case review and quick callback modal
- Staging review/story layouts with images, ready to swap for approved client reviews
- Insights/blog architecture for SEO
- Business-services disclaimer and legal pages
- Vercel preview lead logging fallback
- Supabase-ready persistent lead storage
- Optional GA4 / Meta Pixel consent-gated tracking

## Before production
Add approved company phone/email/address, connect Supabase or CRM, replace sample reviews, and have counsel review final legal/compliance copy for the actual service model and jurisdictions served.
